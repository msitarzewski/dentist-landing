# Fonts

Both faces are variable, self-hosted and under the SIL Open Font License 1.1 (texts beside them).
Neither OFL names a Reserved Font Name, so the Latin subsets keep their family names.

| File | Family | Axes | Source |
|---|---|---|---|
| `anybody-wdth-wght.woff2` | Anybody (Etcetera Type Co) | wdth 50-150, wght 100-900 | Google Fonts, `fonts.gstatic.com/s/anybody/v13`, Latin subset |
| `public-sans-wght.woff2` | Public Sans (USWDS) | wght 100-900 | Google Fonts, `fonts.gstatic.com/s/publicsans/v21`, Latin subset |

Downloaded 2026-11-09. The page makes no request to any font service; these files are all it loads.
The Latin subset covers U+0000-00FF plus the punctuation the page uses (typographic quotes, the
middle dot, the copyright sign). Characters outside it fall back to the system face.
